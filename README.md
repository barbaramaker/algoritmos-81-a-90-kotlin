**Algoritmos 81 a 90 em Kotlin**

Este repositório contém os algoritmos de 81 a 90, originalmente escritos em Portugol e convertidos para Kotlin.

O objetivo da atividade é praticar a linguagem Kotlin e entender como aplicar estruturas condicionais (if/else, ses aninhados) e estruturas de seleção (`when`), além de cálculos matemáticos e verificação de dados.

**Algoritmos desenvolvidos**

- Algoritmo 81: Calcula o dígito verificador de um número de conta corrente de três dígitos.
- Algoritmo 82: Verifica se um número é maior do que 20 e imprime sua metade.
- Algoritmo 83: Verifica se um número é positivo para imprimir seu inverso ou negativo para imprimir seu valor absoluto.
- Algoritmo 84: Verifica se um número lido é par ou ímpar.
- Algoritmo 85: Utiliza ses aninhados para determinar o maior entre três números.
- Algoritmo 86: Verifica se um número é positivo, negativo ou nulo utilizando estruturas condicionais aninhadas.
- Algoritmo 87: Verifica a resposta para a capital do Brasil, considerando diferentes variações de grafia.
- Algoritmo 88: Implementa uma calculadora interativa utilizando opções com condicionais aninhadas.
- Algoritmo 89: Calcula o peso de uma pessoa em diferentes planetas com base em uma opção numérica (estrutura escolha/caso adaptada para `when`).
- Algoritmo 90: Lê um número e o imprime caso seja maior que 20.

**Comentários sobre os exercícios**

Neste bloco, consegui aprofundar o uso de estruturas condicionais simples, compostas, aninhadas e seleções múltiplas.

Também aprendi a lidar com strings, validações de texto, operadores lógicos e a adaptar comandos de escolha do Portugol para o ecossistema Kotlin.

Os exercícios ajudaram a compreender como tomar decisões lógicas no código e estruturar fluxos alternativos de execução.

**Ferramentas utilizadas**

- Kotlin
- IntelliJ IDEA
- Git e GitHub

**Organização**

Os arquivos estão organizados individualmente, de Algoritmo81.kt até Algoritmo90.kt, dentro da pasta src/main/kotlin.

Cada arquivo contém o enunciado, o código original em Portugol e sua conversão para Kotlin.
